# Cozy Read Aloud Web

<img src="public/assets/cozy-cat.png" alt="Cozy Read Aloud" width="88">

无需安装 Obsidian，在浏览器中朗读 Markdown、文本型 PDF、本地 HTML 和 TXT；可选本机 OCR 还支持图片文字和扫描 PDF 单页，校对后朗读。选中文字后起读，在阅读视图中跟随高亮。

**[打开网页版](https://laginae.github.io/cozy-read-aloud-web/)** · [English](README.md) · [隐私说明](PRIVACY.md)

## 快速开始

1. 打开文件，或粘贴文字。默认示例是虚构公开内容。
2. 直接播放可朗读全文；选中文字后，选择“只读选中内容”或“从选中位置继续”。PDF 也支持这两种范围。
3. 在大纲中定位章节，或点击标题旁的播放按钮起读。桌面浏览器还可使用正文右键朗读菜单，设置中可关闭。

默认系统语音不需要密钥。可用音色、音质及是否联网由浏览器和系统决定；标记为本地的音色是浏览器报告的结果。

点击顶部工具栏的语言图标，可一键切换简体中文与 English，也可在设置中选择。切换只改变界面文字，不改变正文、所选音色或播放状态。可选“记住阅读偏好”默认关闭；开启后才记住语言选择，并且只保存语言、倍速、音量、外观及阅读过滤等非敏感偏好。不保存正文、密钥、在线授权、模型或预取开关，关闭此选项即可删除保存的偏好。

## 本版功能

- Markdown、PDF、HTML、TXT 导入，拖放、粘贴及多文档切换。
- PDF 按原始文字位置识别选区，区分重复句子；缩放后保留已捕获的选区。
- 段落与选区高亮、可关闭的自动跟随、大纲搜索、章节或页码起读。
- PDF 首屏渐进预览：后续页面解析时即可查看首页，全文解析完成后才允许播放和导出；停止将丢弃未完成导入。
- 可过滤重复页眉页脚，选择正文、正文与脚注或仅脚注；“只读选中内容”仍保留明确选中的页脚和脚注。
- 长段落内和跨栏/跨页按来源顺序跟随；在线音频按播放进度近似定位，系统语音使用可用的边界事件，不是逐字同步。手动滚动后暂缓跟随四秒。
- 暂停、继续、停止、前后分段、倍速、音量、15/30/60 分钟定时停止。
- PDF 缩放、正文字号、深色外观及手机和平板布局。
- 可选学术模式，复用插件的公式处理和整句优先分段逻辑。
- OpenRouter 在线语音、明确授权、内存密钥、强制 ZDR、有界音频缓存及手动清理。
- 在线音频前进/后退 5 秒。系统语音没有可定位的音频时间轴。
- 按当前朗读范围导出 WAV，单独确认范围与费用，显示进度并可取消。

## 在线语音与导出

在设置中选择 OpenRouter，填写自己的模型 ID、兼容音色 ID 和密钥，确认在线授权后使用。示例不保证提供方当前可用。浏览器调用还受接口 CORS 限制；本项目没有转发服务器，也不内置共享密钥。

请求始终带有 `provider.zdr: true` 与 `provider.data_collection: deny`，失败时不会放宽限制或自动重试。账户日志/共享设置及提供方政策仍需自行核对。详见[隐私说明](PRIVACY.md)。

“在线语音提前准备下一段”默认关闭。开启后只提前合成当前朗读范围内的下一段，最多 500 字符，同时最多两个请求。它可能减少段间等待，但未听到的文字也可能产生费用。暂停、切入后台、停止或改变语音设置会取消待处理任务，不能撤回服务方已收到的请求及费用；返回前台不会自动恢复播放。

设置中可下载等待时间摘要，仅包含播放事件计时及请求/缓存计数，不包含正文、文件名、模型 ID 或密钥。这不是对扬声器实际出声时间的录音测量。

播放状态分别显示等待可用请求、合成、接收音频和准备播放。失败后可手动重试当前段，优先复用已准备的音频；新的在线请求可能收费，不会自动切换提供方或放宽 ZDR。

单次导出最多 **40 段、8,000 字符、5 分钟**，优先复用本次缓存，否则在确认后逐段请求。输出为 1x、单声道、22.05 kHz PCM WAV。取消可以停止后续处理，不能撤回已发请求或其费用。系统语音不能导出音频。

## 尚有边界

这是早期网页版，并非桌面和移动插件的完整复制。单个文本文件限 1 MiB / 250,000 字符，PDF 限 30 MiB / 120 页，同时最多打开八个文档。

PDF 解析组件只在打开 PDF 时加载。PDF 累计提取文字最多 1,000,000 字符，每页最多 50,000 个文字内容项；超限时拒绝导入，不把部分内容当作完整文档朗读。这些是提取后的边界，不保证任意复杂文件都不会消耗大量资源。

“停止”也会取消当前导入及同批剩余文件。打开新文件、切换已有文档或确认粘贴内容后，旧导入不会覆盖当前文档。预览不代表解析完成，不会把不完整全文用于播放或导出。

**本机 OCR 默认关闭。** 在设置中启用后点击扫描图标，打开 PDF/PNG/JPEG/WebP，只识别指定单页，在结果框中校对、选择文字后朗读。约 10 MB 的识别资源包仅在点击识别时加载，并校验哈希；图片不上传，结束、取消、转入后台均释放工作进程。在线音色仍会发送朗读文字。[详细边界](docs/local-ocr.md)。

尚不包含加密 PDF 解锁、PDF 表单、网页 URL 抓取、Copilot 直连、SAPI/OneCore/Edge 本地程序、离线安装。OCR 不理解图片或公式，也不提供扫描原图高亮；复杂 PDF 字体、公式、跨栏及旋转文字仍需要更广泛验证。高亮为段落级，并非逐词同步。

HTML 会移除脚本、表单、图片、iframe、样式和外部链接目标，保留可阅读的基本内容。页面进入后台后会暂停，不承诺锁屏连续播放。正文、密钥和音频缓存只保留在页面内存，刷新后不保留。

## 本地运行

需要 Node.js 24 或以上：

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

打开 `http://127.0.0.1:5186`，服务只监听本机。PDF worker 需要 HTTP(S)，不支持直接双击 HTML 文件。设置 `PORT` 可更换端口。

浏览器验证：安装 `npx playwright install chromium`，保持本地服务运行，再执行 `npm run test:browser`。只使用公开生成的双栏 PDF、虚构正文和模拟在线语音，不调用真实付费账号。

GitHub Actions 完成测试后只将 `dist/` 部署到 Pages。私人文档、密钥、测试输出不是部署输入。来源与许可证见 [VENDORED.md](VENDORED.md)，检查范围见 [VALIDATION.md](VALIDATION.md)。反馈问题时请使用非敏感示例，不要提交私人正文或密钥。
