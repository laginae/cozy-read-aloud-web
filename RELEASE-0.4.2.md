# Cozy Read Aloud Web 0.4.2

- Reading settings no longer reset selection-only or from-selection reading to the whole file. Stale selections must be selected again.
- Fixed bilingual examples preview the current function, interval and table reading style locally. The options apply to the actual queue; no note text, credential or audio service is used to generate the preview.
- Uses Note Reader Core 0.3.2. Long numeric tables and uncertain PDF selections retain their existing protections.
